Devolver un objeto

Hasta ahora hemos devuelto números o textos. También podemos devolver un objeto con varias propiedades: en este caso, nombre y edad.

1. Con llaves y return

const crearPersona = (nombre, edad) => {
    return {
        nombre: nombre,
        edad: edad
    };
};

Las llaves exteriores contienen las instrucciones. Las interiores crean el objeto que devuelve return.



    
2. Sin return y con paréntesis

    
const crearPersonaCorta = (nombre, edad) => ({ nombre: nombre, edad: edad });

    
Los paréntesis permiten devolver directamente el objeto. Sin ellos, las llaves se interpretarían como un bloque de instrucciones.

    


    
3. Acceder a las propiedades

    
En nombre: nombre, la izquierda es la propiedad y la derecha es el valor del parámetro recibido. Lo mismo sucede con edad: edad.

    

    
Aquí this no representa el objeto que devolvemos. Usamos propiedad: valor.


    
Practica

    
Añade un parámetro ciudad y devuelve también esa propiedad en las dos versiones. Crea otra persona con datos diferentes y muestra su ciudad. Lee el código en el editor y comprueba también la consola con F12.
