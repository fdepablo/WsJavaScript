Abrir páginas en otra pestaña o ventana

1. Con un enlace HTML

Para visitar otra página normalmente basta con un enlace; no hace falta JavaScript.

Consultar JavaScript en MDN (abre en otra pestaña o ventana)

2. Con JavaScript

Podemos usar window.open() cuando la apertura forma parte de una acción programada.

3. Solicitar una ventana emergente

Solicitamos una ventana de 600 × 400 píxeles. El navegador y sus preferencias deciden la presentación final y pueden ajustar el tamaño o bloquear la apertura.
